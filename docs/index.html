Overlay
Prompter

A free, transparent teleprompter that floats over any app — Zoom, Teams, TikTok, camera-filter apps — so you read your script while looking straight at the lens. Designed to stay hidden from screen share and recordings on supported systems.

Android 8.0+

Install in a minute

  1. Tap Download APK on your phone.
  2. Open the file. If asked, allow Install unknown apps for your browser or file manager.
  3. If Google Play Protect warns, tap More details → Install anyway. (It's not on the Play Store, so Play Protect doesn't recognize it.)
  4. Open Overlay Prompter, paste or share your script into it, and tap Start.
  5. On first run, tap Open permission settings and enable Display over other apps.
  6. Allow notifications (Android 13+) for pause / hide / stop, then open any app — the prompter stays on top.

Screen-capture hiding depends on device and Android version. A camera recording never includes the overlay — the camera only sees the lens, not the screen. iOS isn't supported (it doesn't allow drawing over other apps).

Windows / macOS

Desktop

An Electron app with global hotkeys: Ctrl+Shift+Space play/pause · Ctrl+Shift+↑/↓ speed · Ctrl+Shift+L click-through · Ctrl+Shift+H hide. Installers aren't published yet — build from source:

npm install → npm start · installers: npm run dist:win / npm run dist:mac
