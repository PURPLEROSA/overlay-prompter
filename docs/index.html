Overlay Prompter

built by Shelly Or Gisser

A free, transparent teleprompter that floats over any app — Zoom, Teams, TikTok, camera-filter apps — so you read your script while looking straight at the lens. Designed to stay hidden from screen share and recordings.

Features

Floats over everything

Always on top of Zoom, Teams, TikTok, Instagram, camera and filter apps.

Hidden from capture

Uses OS content protection (FLAG_SECURE / setContentProtection) to stay out of screen shares and recordings on supported systems. Always test before going live.

Smooth auto-scroll

Play/pause, speed control, jump back/forward, highlighted reading line.

Your layout

Drag, resize, font size, background opacity, mirror mode, click-through lock.

Hebrew & RTL ready

Full right-to-left support with the Heebo font, plus English.

Free & private

No account, no ads. Scripts stay on your device.

Install on Android (8.0+)

  1. Tap Download APK on your phone.
  2. Open the downloaded file. If asked, allow Install unknown apps for your browser or file manager.
  3. If Google Play Protect warns about an unknown app, tap More details → Install anyway. (The app isn't on the Play Store, so Play Protect doesn't recognize it.)
  4. Open Overlay Prompter, paste or share your script into it, and tap Start.
  5. On first run, tap Open permission settings and enable Display over other apps.
  6. Allow notifications (Android 13+) for pause/hide/stop controls.
  7. Open TikTok, Zoom or any app — the prompter stays on top.

Screen-capture hiding depends on the device and Android version. A camera recording never includes the overlay — the camera only sees the lens, not the screen. iOS isn't supported (it doesn't allow drawing over other apps).

Desktop (Windows / macOS)

The desktop version is an Electron app with global hotkeys (Ctrl+Shift+Space play/pause, Ctrl+Shift+↑/↓ speed, Ctrl+Shift+L click-through, Ctrl+Shift+H hide). Installers aren't published yet — build from source:

npm install → npm start · installers: npm run dist:win / npm run dist:mac
